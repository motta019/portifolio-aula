# Funcionalidades em ordem de prioridade

## P0 — estrutura obrigatória
1. Hero/topo com nome, frase principal e botão “Ver projetos”.
2. Menu fixo com links âncora para Sobre mim, Projetos e Contato.
3. Sobre mim com arte ou foto real (quando fornecida), formação e competências.
4. Galeria com **dois projetos acadêmicos**, título, explicação e prévia visual; adicionar links apenas quando reais.
5. Contato com campos nome, e-mail e mensagem, com validação HTML; sem backend, botão para **copiar mensagem**, com feedback verdadeiro.

## P1 — acabamento e usabilidade
6. Layout responsivo para celular, tablet e computador; menu mobile navegável.
7. Botão de tema claro/escuro, com preferência salva localmente quando possível.
8. Scroll suave e transições discretas; respeitar configuração de movimento reduzido.
9. Foco visível no teclado, rótulos para inputs, textos legíveis e acessibilidade básica.

## P2 — revisão e publicação
10. Conferir erros no console, links internos, imagens e campos do formulário.
11. Substituir ilustrações por capturas reais dos projetos, caso disponíveis.
12. Publicar repositório no GitHub e site na Vercel, usando as contas do aluno.
13. Entregar URL pública, GitHub e PDF de referências até 01/11/2026.
